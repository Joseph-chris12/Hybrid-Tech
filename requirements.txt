Chacing - Kebutuhan untuk Menjalankan Proyek
============================================

Proyek ini adalah aplikasi React Native (Expo). Dependency JavaScript
dipasang otomatis dari package.json dengan perintah `npm install`,
bukan lewat `pip install -r requirements.txt`. Berkas ini hanya
dokumentasi daftar kebutuhan dan versi yang dipakai saat pengembangan.


1. Kebutuhan Sistem
-------------------
Node.js            ^20.19.4 / ^22.13.0 / ^24.3.0 (diuji dengan v24.21.0)
npm                11.x (diuji dengan 11.19.0)
Git                versi terbaru

Untuk menjalankan di HP:
Expo Go            versi yang mendukung Expo SDK 57 (Android / iOS)

Opsional, untuk development build:
Xcode              (iOS, khusus macOS; diuji dengan Xcode 27.2)
CocoaPods          (iOS; diuji dengan 1.17.0)
Android Studio     (Android SDK + emulator)
